
# Предварительные испытания H-07

Дата: 19.11.2026
Модель: GigaChat-3-Lightning
Тип данных: синтетические

## USN-DEMO-01

Ситуация:
Не хватает одного судьи.
J03 доступен, J04 недоступен.

Результат:
Модель рекомендовала J03.

Оценка: успешно с замечанием.

Замечание:
Модель сослалась на соответствие рейтинга
требованиям квалификации, хотя минимальные
требования не были предоставлены.

## USN-DEMO-02

Ситуация:
Не хватает одного судьи.
J03 и J04 недоступны.
J01 и J02 уже назначены.

Результат:
Модель рекомендовала J02.

Оценка: провалено.

Причина:
J02 уже назначен и отсутствует в списке
дополнительных кандидатов.
Модель ошибочно объявила его доступным.

## Предварительный вывод

Модель успешно обработала простой случай
с одним доступным кандидатом, но допустила
ошибку при отсутствии допустимых назначений.

Требуется программная проверка рекомендаций.
Результаты не подтверждают гипотезу H-07.

# Сравнительный эксперимент H07-v1.0

Дата: 19.11.2026

## Условия эксперимента

Проверены три модели:

- GigaChat-3-Lightning
- GigaChat-3-Pro
- GigaChat-2-Pro

Использованы 7 синтетических сценариев,
по 3 повторных запуска для каждой модели.

Всего выполнено 63 запроса.

Для всех моделей применялся единый шаблон
промпта версии H07-v1.0.

Проверка рекомендаций выполнялась
Python-валидатором.

## Результаты

| Модель | Успешно | Успешность |
|---|---:|---:|
| GigaChat-3-Lightning | 18/21 | 85,7% |
| GigaChat-3-Pro | 14/21 | 66,7% |
| GigaChat-2-Pro | 21/21 | 100% |

Среднее время ответа:

- GigaChat-3-Lightning: 0,313 с
- GigaChat-3-Pro: 0,950 с
- GigaChat-2-Pro: 0,843 с

## Выявленные ошибки

GigaChat-3-Lightning:

В сценарии USN-DEMO-06 трижды отказалась
предлагать судью, хотя существовали
допустимые кандидаты.

GigaChat-3-Pro:

В сценариях USN-DEMO-01, USN-DEMO-03
и USN-DEMO-05 ошибочно отказывалась
от назначения доступных кандидатов.

В одном из объяснений модель сослалась
на ограничение по рейтингу,
не предусмотренное исходными правилами.

GigaChat-2-Pro:

Все 21 ответа прошли автоматическую
проверку ограничений.

## Предварительные выводы

На текущем наборе синтетических сценариев
наиболее точные результаты показала
GigaChat-2-Pro.

GigaChat-3-Lightning продемонстрировала
наименьшее среднее время ответа.

Полученные результаты позволяют
