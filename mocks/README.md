# Тестовые данные (моки)

Все данные здесь **выдуманы** и повторяют структуру из ТЗ: соревнования, открытые роли,
судейские слоты и заявки. Их достаточно, чтобы разрабатывать и тестировать без доступа к API заказчика.

- `competitions.json` — 4 соревнования: классика, экспресс (регистрация игроков уже закрыта),
  командный формат и экспресс с **ошибкой конфигурации** (открыт секундант) — для проверки этого случая.
- `registrations.json` — 18 судей и 4 игрока на классику. В слотах 06:00–08:00 и 12:00–14:00 судей специально мало (нужно 7),
  чтобы на карте доступности был «проблемный слот».

Реальную обезличенную таблицу таймингов заказчика (`Дубна_ USN соревнования.xlsx`) в репозиторий
**не кладём** (в `.gitignore`: `data/`, `*.xlsx`). Её разбор — отдельная задача (гипотеза H-02).
